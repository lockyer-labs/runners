Questions

Which GitHub Actions runner is the fastest?

On Linux x64, Avrea built Redis fastest, in 22.5 s, ahead of Buildkite (23.4 s) and Luxor (23.6 s). On Linux arm64, Avrea built Redis fastest, in 19.3 s, ahead of Depot (38.5 s) and FlameWill (40.0 s). On macOS, Groundbox built Redis fastest, in 12.9 s, ahead of Avrea (13.8 s) and Blacksmith (16.7 s). Build time is the median of three runs of make -j on the Redis source.

Which GitHub Actions runner is the cheapest?

On Linux x64, Celesto was the cheapest pay-as-you-go runner at $0.0011 per Redis build, against $0.0120 for GitHub. boat's compute cost was lower, at $0.0003, but extra costs apply: Needs a plan from $20 a month, which comes back as VM time. Job starts above the plan's included number cost $0.03-0.07 each. On Linux arm64, FlameWill was the cheapest pay-as-you-go runner at $0.0022 per Redis build, against $0.0080 for GitHub. On macOS, Groundbox was the cheapest pay-as-you-go runner at $0.0108 per Redis build, against $0.0800 for WarpBuild. Costs use each provider's list price and how it rounds a job's duration; providers that need a plan or charge other fees are listed but not ranked cheapest.

Which runner providers are compared?

Linux x64: Avrea, Blacksmith, Buildkite, Celesto, Checklane, Depot, GitHub, Groundbox, Luxor, Namespace, Ubicloud, WarpBuild and boat. Linux arm64: Avrea, Blacksmith, Depot, FlameWill, GitHub, Ubicloud and WarpBuild. macOS: Avrea, Blacksmith, Depot, GitHub, Groundbox, Luxor and WarpBuild. Linux runners are each provider's 4 vCPU size on Ubuntu 24.04; Macs are each provider's smallest Apple Silicon size on macOS 26.

How are the runners benchmarked?

Every runner runs the same script at the same moment, three times: sysbench CPU and memory tests after a warm-up, fio sequential and 4k random disk tests, a download from Cloudflare, package installs, a 1 GB actions/cache save and restore, and a Redis build. Queue time comes from the GitHub API. The site shows each metric's median and the spread across runs.

Why do some runners cost more for short jobs?

Blacksmith, FlameWill, GitHub, Namespace, Ubicloud and WarpBuild bill by the minute, rounding every job up, so a 25-second job is charged as a full minute. Per-second providers charge only for the time used, which makes a large difference for short jobs.

How often are the results updated?

The benchmark runs weekly on GitHub Actions and the code is open source. These results were updated on 26 November 2026, covering 14 providers.
